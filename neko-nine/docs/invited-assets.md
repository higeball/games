# 特別招待選手画像の制作記録

組み込み image_gen ツールで、ユーザー提供の各参考画像から猫のポートレートを新規生成。背景のアルファ透過を保持しています。

## shiroxler

保存先: public/characters/invited/shiroxler.png

最終プロンプト:

Use case: stylized-concept. Asset type: one transparent portrait for the special invited baseball player シロックスラー in a Japanese cat baseball management game. Input image 1 is the character identity reference only: use its face, hair, glasses, build and expression as recognizable cues. Create a new anthropomorphic CAT baseball player, not a human with cat ears. Subject: a white-furred cat with silver thin rectangular glasses, short closely cropped black hair tuft, thick softly arched black eyebrows, closed smiling crescent eyes, a small friendly smile, subtle charcoal muzzle shadow recalling the reference stubble. The entire face must have a real feline muzzle, small cat nose, whiskers and triangular cat ears, with human-reference hairstyle and glasses retained. Wear an ivory baseball jersey with navy trim, no cap so the recognizable hairstyle is visible. Style: polished warm Japanese anime game illustration, clean dark outlines, restrained cel shading, friendly compact proportions; a slightly more detailed special character portrait than the ordinary pixel cats is intentional. Composition: one centered head-and-shoulders bust, ears, hair and shoulders entirely inside a square frame with generous clear padding, facing the viewer. Genuinely transparent alpha background. No scenery, no extra characters, no sheet, no text, no watermark. Retain the specific identifying features of this reference.
