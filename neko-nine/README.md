# ネコナイン 〜ヤス監督の挑戦〜 (Neko Nine)

個性豊かな猫選手9匹をドラフト＆育成し、ヤス監督の絶妙な采配でリーグ優勝を目指す本格短編野球シミュレーションゲームです。

---

## 🎮 ゲームの特徴

1. **ドラフト会議**:
   - 投手・内野手・外野手など、個性的な猫選手たちをスカウト。
   - 約5%の確率で出現する能力値の高い「★スペシャル選手」（ゴールドフレーム＆光彩エフェクト演出）。
2. **育成キャンプ**:
   - 9匹の猫選手を一覧表示。
   - 3種類の育成メニューを選択後に一括確定する計画的育成UI。
3. **Three.js 3Dスタジアム＆リアルタイム試合画面**:
   - 臨場感あふれる3D野球スタジアム（マウンド、バッターボックス、フェンス、観客席、空）。
   - スコアボード、イニング、表（攻撃）／裏（守備）の明確なインジケーター。
   - ランナー状況（一塁・二塁・三塁）とアウトカウントの可視化。
   - 采配選択後の投球・打撃アクション＆ダイナミック結果バナー。
4. **スマートフォン（iPhone 13 Pro等）最適化**:
   - 縦スクロールを最小限に抑え、1画面で快適に操作できるレスポンシブレイアウト。

---

## 🛠️ 技術スタック

- **UI / フレームワーク**: React 19, TypeScript
- **3Dグラフィックス**: Three.js
- **ビルドツール**: Vite
- **テスト**: Vitest, React Testing Library

---

## 🚀 単体開発・ビルド方法

```bash
# 依存関係インストール
npm install

# 開発サーバー起動（ポート5173）
npm run dev

# テスト実行
npm run test

# プロダクションビルド
npm run build
```
