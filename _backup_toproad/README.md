# もじさん＆ゲイリーのゲート突破大作戦（Top Road Runner）

iOS人気ゲーム『トップロード』の爽快なゲート突破アクションを再現した、スマホブラウザ向け3Dラン＆ガンシューティングゲームです。

頼れるサラリーマン「**もじさん**」と、相棒の緑色スライム「**ゲイリーくん**」が電脳ハイウェイを疾走し、ゲートを撃って増殖しながら巨大ボスに立ち向かいます！

---

## 🎮 ゲームの特徴

1. **もじさん＆ゲイリーの共闘アクション**:
   - 中央でもじさんが強力レーザーを掃射！
   - ゲートをくぐるたびにゲイリーくんが `+10`, `×2` など爆発的に増殖！
   - ゲイリーがポヨンポヨンと跳ねながら、前列から大量のスライム弾幕を一斉掃射！
2. **ゲート育成シューティング**:
   - ゲートに弾を撃ち込むと、ゲートの数値がどんどん成長（+5 → +15など）！
   - 射撃で育ててから飛び込む爽快な戦略性。
3. **スマホ片手プレイに最適化**:
   - 画面のどこを触っても左右に快適にスワイプ・ドラッグ可能。
   - レスポンシブ縦画面（Portrait）最適化。
4. **Three.jsによる高品質3Dグラフィック & 60fps**:
   - `InstancedMesh` により、ゲイリーが100体以上増殖してもスマホでヌルヌル動作！
   - 撃破パーティクル、画面シェイク、撃破スロー、紙吹雪演出。
5. **完全内蔵サウンド（外部ロード遅延ゼロ）**:
   - Web Audio API によるプロシージャル効果音＆疾走感あふれるシンセBGM。

---

## 🕹️ 操作方法

| 操作 | アクション |
| :--- | :--- |
| **スマホ：画面左右スワイプ/ドラッグ** | 部隊の左右移動 |
| **PC：マウスドラッグ / [A][D]キー / [←][→]キー** | 部隊の左右移動 |
| **射撃** | オートショット（自動） |

## 🚀 ローカル起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバ起動（ホットリロード対応）
npm run dev
```

ブラウザで `http://localhost:3000` を開いてプレイできます。

---

## 📦 GitHub Pages への公開

本プロジェクトは GitHub Actions の自動デプロイワークフロー（`.github/workflows/deploy.yml`）を含んでいます。

1. GitHub リポジトリの Settings > Pages を開きます。
2. **Build and deployment > Source** を **「GitHub Actions」** に設定します。
3. リポジトリの `main`（または `master`）ブランチへコードをプッシュすると、自動的にビルドされ GitHub Pages に公開されます！

また、手動でビルドする場合は以下を実行します：
```bash
npm run build
```
`dist/` ディレクトリ内に完全な静的サイトが出力されます。
