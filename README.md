# もじさんの不思議のダンジョン (Moji-san's Mystery Dungeon)

『トルネコの大冒険 不思議のダンジョン』のゲームシステムを完全再現した、本格ローグライクRPGです。
入るたびに形が変わるダンジョン、ターン制の戦略的戦闘、満腹度管理、多種多様なアイテム（草・巻物・杖・パン・武具）を駆使して、地下10階に眠る秘宝「**奇跡の箱**」を持ち帰りましょう！

※旧アクションゲームは `_backup_toproad/` に安全に退避・保存されています。

---

## 🎮 ゲームの特徴

1. **ターン制・グリッド移動（8方向対応）**:
   - 自分が1歩動く／行動すると、モンスターも1歩動く完全同期ターン制。
   - 斜め移動・角抜け制限、足踏み（ターン送り＆自然回復）、素振りに完全対応。
2. **ランダム生成ダンジョン**:
   - 部屋と通路を自動生成。モンスター、アイテム、隠されたワナ（毒矢・地雷・睡眠・転び石・ワープ）を配置。
   - 部屋に入ると部屋全体を視認、通路では1マス視界の緊張感。
3. **満腹度（お腹のすき具合）システム**:
   - 歩くたびにお腹が減り、0%になると毎ターン1HPの飢餓ダメージ。
   - パンを食べて回復。満腹時に「大きいパン」を食べると最大満腹度が上昇！
4. **本格的なアイテム＆装備システム**:
   - **武器＆盾**: こんぼう、どうのつるぎ、鉄の斧、皮の盾（腹減り半減）、うろこの盾（毒無効）など。
   - **草・種**: 薬草、弟切草、毒けし草、ちからの種、胃拡張の種、ルーラ草、火炎草（30ダメージ炎）、睡眠草。
   - **巻物**: あかりの巻物（全マップ開示）、強化の巻物（武具+1）、バクスイの巻物、混乱の巻物、聖域の巻物。
   - **杖**: 吹き飛ばしの杖、場所替えの杖、かなしばりの杖、封印の杖、へんげの杖。
   - **投擲**: 矢やアイテムをモンスターに向けて投げることが可能！
5. **多彩なモンスター＆AI**:
   - スライム、ドラキー、ゴースト、おばけキノコ（ちから下げ）、まどうし（ラリホー）、くさった死体（パン腐敗）、はぐれメタル（逃走・高EXP）、ゴーレム、ドラゴン（炎ブレス）。
6. **スマホ・PC両対応操作**:
   - スマホ：8方向バーチャルパッド＋直感的なアクションボタン（攻撃、道具、待機、向き変更、矢）。
   - PC：矢印キー／テンキー／Viキー（HJKL）＋Space攻撃＋I（道具）＋X（足踏み）。
7. **レトロDQサウンド**:
   - Web Audio APIによる完全内蔵の8-bitプロシージャル効果音（斬撃、レベルアップ、ファンファーレ等）。

## 🕹️ 操作方法

### スマートフォン
- **8方向パッド**: 移動（中央ボタンは足踏み）
- **⚔️ 攻撃**: 目の前の敵を攻撃 / 素振り
- **🎒 道具**: 所持品メニュー（使う、食べる、飲む、読む、振る、装備、投げる、置く、降りる）
- **⏳ 待機**: 1ターン待機（HP回復）
- **🔄 向き**: 移動せずにその場で向きだけを変えるモード切替
- **🏹 矢**: 所持している矢を正面へ射出
- **🗺️ 地図**: ミニマップ表示切替

### PC キーボード
| キー | アクション |
| :--- | :--- |
| **矢印キー / テンキー (1-9) / Vi (hjklyubn)** | 8方向移動 |
| **Space / Enter** | 正面の敵を攻撃 / 素振り |
| **I / E** | 道具（インベントリ）を開く |
| **X / . / テンキー5** | 足踏み（ターン送り） |
| **Shift + 方向キー / Z** | 向き変更のみ |
| **F** | 矢を射る |
| **M** | ミニマップ切替 |
| **Esc** | メニューを閉じる |
