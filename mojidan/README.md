# もじダン 〜午後の始業と消えたトイレ〜 (Moji-san's Mystery Dungeon)

『トルネコの大冒険 不思議のダンジョン』のゲームシステムを完全再現した、本格ローグライクRPGです。
株式会社ヒゲボールが入居する地上50階建てのオフィスタワーで、昼休みの激辛カレーにより激痛に襲われた会社員・もじさん。
配管破裂で閉鎖されたトイレを求め、エレベーターも停止したタワーの50Fから40Fへ非常階段を駆け降りろ！

---

## 🎮 ゲームの特徴

1. **ターン制・グリッド移動（8方向対応）**:
   - 自分が1歩動く／行動すると、モンスターも1歩動く完全同期ターン制。
   - 斜め移動・角抜け制限、足踏み（ターン送り＆自然回復）、素振りに完全対応。
   - 長押し連続移動と1歩タップ移動の誤操作防止チューニング済み。
2. **ランダム生成ダンジョン**:
   - 部屋と通路を自動生成。モンスター、アイテム、隠されたワナ（滑る床・漏電・睡魔・LANケーブル・迷走エレベーター）を配置。
   - 部屋に入ると部屋全体を視認、通路では1マス視界の緊張感。
3. **満腹度（お腹のすき具合）システム**:
   - 歩くたびにお腹が減り、0%になると毎ターン1HPの飢餓ダメージ。
   - パンを食べて回復。満腹時に「大きいパン」を食べると最大満腹度が上昇！
4. **本格的なアイテム＆装備システム**:
   - **武器＆盾**: こん棒、銅の剣、鉄の斧、ドラゴンキラー、はぐれメタルの剣、正義のソロバン、皮の盾、うろこの盾、鋼鉄の盾、ドラゴンシールド、はぐれメタルの盾など。
   - **草・種**: 薬草、弟切草、毒けし草、ちからの種、胃拡張の種、ルーラ草、火炎草、睡眠草、目薬草。
   - **巻物**: あかりの巻物、強化の巻物、聖域の巻物、バクスイの巻物、混乱の巻物、パンの巻物、インパスの巻物。
   - **杖**: 吹き飛ばしの杖、場所替えの杖、かなしばりの杖、封印の杖、へんげの杖。
   - **矢・投擲**: 木の矢・鉄の矢の射出、アイテム投擲に対応。
5. **多彩なモンスター＆AI**:
   - スライム、ドラキー、ゴースト（2倍速）、おばけキノコ（ちから下げ）、まどうし（睡眠呪文）、くさった死体（盾サビ・パン腐敗）、はぐれメタル（逃走・高EXP）、ゴーレム、ドラゴン（炎ブレス）。
6. **スマホ・PC両対応操作**:
   - スマホ：8方向バーチャルパッド＋直感的なアクションボタン（攻撃、道具、足踏、向き、矢）。
   - PC：矢印キー／テンキー／Viキー（HJKL）＋Space攻撃＋I（道具）＋X（足踏み）。
7. **レトロサウンド＆演出**:
   - Web Audio APIによる8-bitプロシージャル効果音。

## 🕹️ 操作方法

### スマートフォン
- **8方向パッド**: 移動（中央「向き」ボタンで向き変更モード）
- **⚔️ 攻撃**: 目の前の敵を攻撃 / 素振り
- **🎒 道具**: 所持品メニュー（使う、食べる、飲む、読む、振る、装備、投げる、置く、降りる）
- **⏳ 足踏**: 1ターン待機（HP回復）
- **🔄 向き**: 移動せずにその場で向きだけを変える
- **🏹 矢**: 所持している矢を正面へ射出
- **🗺️ 地図**: ミニマップ表示切替
- **💾 中断**: 冒険の途中セーブ

### PC キーボード
| キー | アクション |
| :--- | :--- |
| **矢印キー / テンキー (1-9) / Vi (hjklyubn)** | 8方向移動 |
| **Space / Enter** | 正面の敵を攻撃 / 素振り |
| **I / E** | 道具（インベントリ）を開く |
| **X / . / テンキー5** | 足踏み（ターン送り） |
| **Shift + 方向キー / Z** | 向き変更のみ |
| **F** | 矢を射る |
| **M** | ミニマップ切替 |
| **Esc** | メニューを閉じる |
